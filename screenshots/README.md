# Week 5 Assignment - Hands-On Lab

`countdown.py` - Uses a while loop to count down from a number chosen by the user and prints "Blast off!" when the countdown finishes.

`guess_game.py` - Uses a while loop to run a number guessing game with hints and an attempt counter.

`spell_it_out.py` - Uses two for loops to print each letter of a word and then print each letter with a number.

I would use a while loop when I don't know exactly how many times I need to repeat something and want the loop to continue until a condition is met. I would use a for loop when I know I need to go through each item in a sequence, such as each letter in a word.
